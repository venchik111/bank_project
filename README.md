# Bank_project

## Описание:

Bank_project - это виджеты банковских операций клиента
## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/venchik111/bank_project.git
```
2. Установите зависимости:
```
poetry install
```
## Использование:

1. Импортируй модули из src
2. Взгляни на функции и их описание
3. Используй для своих задач
